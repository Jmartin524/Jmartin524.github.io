  • Image Classification using Python, TensorFlow, Matplotlib, and NumPy

    This image classification project leverages a Convolutional Neural Network (CNN) to differentiate between AI-generated and real images. The workflow includes preprocessing images by resizing, augmenting, and normalizing them to improve model robustness. Using TensorFlow, the CNN model was trained with data augmentation, dropout, and L2 regularization to prevent overfitting. A binary classification approach enabled accurate prediction by training the model on labeled datasets of real and AI-generated images. The project also features a custom image classification function, which allows users to upload images and receive real-time predictions. This interactive aspect, along with model saving and loading capabilities, showcases the full deployment cycle for an image classifier model.

  • Buy Sell or Hold ML Model

    A Python-based application that utilizes machine learning to analyze Exchange-Traded Funds (ETFs) and provide actionable investment signals. By leveraging historical price data from Yahoo Finance, the program employs a Random Forest Classifier to predict the direction of price movements, generating buy, sell, or hold recommendations based on the analysis. Key features of the program include: Data Fetching: Automatically retrieves historical price data for selected ETFs over a dynamic five-year period, ensuring up-to-date analysis. Feature Engineering: Computes returns and market direction, preparing the data for machine learning modeling. Predictive Modeling: Trains a Random Forest Classifier to predict price direction, enabling informed investment decisions. Visual Insights: Presents cumulative returns and prediction signals in a visually appealing dark mode chart, enhancing user experience. This program serves as a valuable tool for individuals interested in financial markets and the application of machine learning in investment analysis.
